# VAI — Fix-Everything Plan (phased, checkpoint after each commit)

**Context:** VAI is an AI wardrobe stylist (Expo + Supabase edge functions + Gemini renders). Audit found: auth providers disabled on the project (the 400s), session-less edge calls (the 401s), 4 missing/misbehaving backend pieces, a forgeable Apple webhook (P0), ~40 flow/UI/state bugs, and 3 fake-data violations. Fixes are grouped into 6 commits, each verified before the next.

---

## Phase 0 — Ops checklist (manual, not code — do first)
1. Supabase dashboard → Authentication → Providers: **enable Google + Apple** with credentials (root cause of all 400s).
2. Verify signup email delivery (Auth → Emails); add custom SMTP if rate-limited (root cause of stuck 401s).
3. Rotate `SUPABASE_DB_PASSWORD` (was shared in chat) and remove it from `.env`.
4. `supabase db push` + deploy all edge functions; set secrets (`APPLE_BUNDLE_ID`, `GOOGLE_PUBSUB_SERVICE_ACCOUNT`, `INNGEST_*`, `GEMINI_API_KEY`…).
5. Verify the 4 storage buckets exist (created by migration 0001).

## Phase 1 — Security: edge functions + migration 0007
- **billing-apple**: real JWS verification — x5c chain to embedded Apple Root CA (WebCrypto ECDSA P-256), require `APPLE_BUNDLE_ID`, validate environment, dedupe on `notificationUUID` (supabase/functions/billing-apple/index.ts).
- **billing-google**: verify Pub/Sub OIDC JWT (Google JWKS fetch, RS256, iss/aud/exp); fail closed when the service-account secret is unset (supabase/functions/billing-google/index.ts).
- **Migration 0007**: unique index on `ledger(type, meta->>'provider_event_id')` (kills Stripe double-credit); `grantPackCredits` becomes a single atomic UPDATE; narrow `users` INSERT grant to `(id, email)` (kills referral self-minting); `charge.refunded` debits pack credits (billing-stripe/index.ts).
- **SSRF guard** `_shared/net.ts`: https-only, block private/loopback/link-local/metadata IPs after DNS resolve, cap content-length, require image content-type. Apply to render-tryon ingest, gemini `urlToInlinePart`, fashn, pinterest fetches. Pipeline accepts only in-bucket storage paths for `base_photos.url`/`garments.image_url` (ownership-validated), never freeform client URLs.
- **Idempotency griefing**: render-tryon + restyle core catch 23505 → refund allowance → 409 `idempotency_conflict`.
- **Inngest enqueue failure** (_shared/pipeline.ts): refund allowance + mark render `failed` (no longer reusable-queued).
- **restyle**: `bumpRestyleDaily` moves after cache/dedupe hit determination.
- **Referral**: mint 6-char codes; redemption accepts `VAI-[A-Z0-9]{4,6}` (legacy 4-char); `already_linked` re-checks qualification and credits when now-eligible; `paywall-status` returns `referral_code`; client redeems `referredBy` at auth finish (not only paywall mount).
- **Stripe webhook**: stop logging full event bodies (PII). Remove ACAO `*` from webhook endpoints.

## Phase 2 — Signed URLs everywhere (renders privacy)
- Migration 0007 also: add `renders.output_path`; drop `renders_public_read` policy. Garments bucket stays public-read (clothing shots, no faces) — documented accepted risk.
- `_shared/pipeline.ts`: store bucket-relative path; every render-serving response mints a 1h signed URL: render-tryon (submit + `action:'status'`), restyle, reel-drop, reel-regenerate, and the new reel-week.
- Client already consumes `outputUrl`/`imageUrl` from responses — no shape change. Stale MMKV-cached reel card URLs self-heal via the poller/refresh added in Phase 4.

## Phase 3 — Auth/session (client)
- **_layout.tsx** `onAuthStateChange`: on `SIGNED_OUT`/`TOKEN_REVOKED` → `clearAuth()` + route to `/onboarding/auth` when in tabs (kills the 401-cascade-while-"signed-in" bug).
- **Cross-user bleed**: session store persists `funnelOwnerId`; `finish()` resets closet/quiz/reel/quotas/taste when the persisted data belongs to a different user. Logout adds: `useQuiz.reset`, taste-prefs reset, `resetAnalytics()`, `setSentryUser(null)`, `cancelScheduledReminders()`, `Purchases.logOut` (new `logOutBilling()` helper).
- **auth.tsx**: `handleEmail` deps + `readAgeGate` (birth-year bug); Apple cancel detection `/cancel/i` + always `setBusy(null)`; busy-guard on `handleApple`; "provider is not enabled" → honest "Google/Apple sign-in isn't set up for this build yet — use email".
- **auth/callback.tsx**: poll `getSession()` up to 3s before "did not complete" (Android OAuth flash).
- **app/index.tsx**: `STEP_ROUTE[step] ?? '/onboarding'` (unknown persisted step crashes boot).
- **selfie-capture.tsx**: denied view gains Back / Choose-from-library / Open Settings; web renders the upload panel without a camera-permission gate; dedupe the two "use anyway" buttons; block Back during upload. closet-min3: library source tagged `'bulk'`.
- **Push**: `registerPushToken()` called once per user after sign-in; `savePushToken` always sends the session Bearer token; render-ready push taps route to the tryon tab with `renderId` (router + cold-start stash).
- **billing.ts**: `logIn()` on account switch instead of re-`configure`; `restore()` reports restored only when the status fetch succeeded and tier ≠ free; web platform short-circuits to `not-configured`.

## Phase 4 — Flow/UI blockers (client)
- **Closet trap**: closet-min3 supports `?mode=app` (no funnel-step mutation, Back → tabs, no step regression); closet.tsx pushes that mode.
- **tryon.tsx**: `canGenerate` drops the quota clause (button enabled, label "Get more renders" routes to paywall — existing handler branch becomes reachable); poller aborts on UNAUTHENTICATED/`render_not_found` instead of 95s-to-fake-timeout; render done also updates the paywall mirror (premium badges decrement in-session).
- **reel.tsx**: double-submit guard (`actionDisabled`/`actionLoading` + in-flight check); poller every 8s while any card has empty `imageUrl` (5-min cap); pose status refetch on focus (`useFocusEffect`); pose-status fetch error → retry state, not "needs 3 poses"; visible worn feedback; Pinterest share with null URL shows an error instead of silent no-op.
- **Home (tabs/index.tsx)**: tier-aware QuotaBadge (free: X of 5; trial/premium: X of 30 monthly); Save resets when the outfit changes + disables after save; null-URI thumbs filtered; raw outfit UUID shown only in `__DEV__`.
- **shop.tsx**: cards become pressable → `buildOutboundUrl` + `expo-web-browser` (added to package.json via `npx expo install`); hydration merge so in-flight hearts aren't clobbered; signed-out heart → sign-in prompt; duplicate-key fallback in keyExtractor.
- **Fake-data violations**: quiz `skipWithDefaults` result gets "Your starter style" headline, no share card; first-outfit fallback card captioned "Starter look — not AI styled"; RenderProgress pips become state-driven (poll transitions) instead of a blind timer. The "usually ~20s" line stays — it's founder-locked copy (CONTRACT-frontend §7; flag for your review separately).
- **profile.tsx**: "Renders used" copy tier-aware; style-score section consumes the new function, `percentile` null-tolerated. **pinterest-boards.tsx**: persist board selection map.

## Phase 5 — New edge functions
- **reel-week/index.ts**: GET `?week_of` (+ POST alias) → `requireUser` → read `reel_drops` by (user, week) → join renders + outfits for card metadata → mint signed image URLs → `{ week_of, cards, tier }` envelope or null.
- **style-score/index.ts**: `requireUser` → deterministic 0–100 scoring computed from the user's real data (fit: outfit/garment season-formality coverage; color: palette coherence + color diversity; vers: category-combination breadth + wear counts; occasion: formality 1–5 spread; weighted total). `percentile: null` until population stats exist. Formula documented in the file header — no invented numbers.
- Both: JWT, ownership-scoped, http envelope, read-only (no quota).

## Phase 6 — Client libs / hardening
- **render-queue.ts**: dead-lettered actions move to a capped persisted `deadLetter` list and the loop continues (fixes dropped-outbox-actions + poison-retry-forever); `retry()` actually resubmits.
- **edge.ts**: cap honored `Retry-After` at ≤30s.
- **Idempotency keys**: planner includes garment/history/laundry hash; auto-tag hashes full image content (not first 48 bytes); shop-picks includes budget/limit/gap.
- **image-pipeline.ts**: release `ImageRef`s (try/finally), delete temp files after upload, max-edge resize (1024 cap on the long side), full-content sha for resumable uploads, cap restyle note + tagging hint at 280 chars.
- **Dead code removal**: `generateWhyLine`/`WHY_TEMPLATES`, the unused `lib/perf/quotas.ts` guard layer and cache invalidators.
- **mapProductPick**: no invented "ShopStyle"/$0.00 — blank retailer, hidden price when absent.
- **Analytics/Sentry**: call `initAnalytics()`/`initSentry()` in _layout; `identify` on sign-in; emit the existing taxonomy events (`paywall_seen`, `trial_started`, purchase success/error) from the paywall store — billing funnel becomes measurable.
- **Stores**: add `version: 1` + migrate to every persisted store (future-proof rehydration).
